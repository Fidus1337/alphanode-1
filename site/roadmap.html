Roadmap · 2026 – 2028

From one honest node
to a network that breeds alpha.

Today AlphaNode is a solitary miner: your machine, your formulas, honest tests. Over the next two years it grows a mind of its own, then a society — an agent inside every node, a network between them, a breeding loop across the network, and an economy that pays the contributors. In that order, each stage shipping as product.

principle 01

Honesty is not negotiable

Every future feature inherits today's rules: locked out-of-sample tests, forward tracking on closed bars, full costs. A network makes overfitting easier — so the referee gets stricter, never looser.

principle 02

Sealed by design

Formulas never travel in plaintext. The vault that today protects a single library is the same machinery that will let strangers' nodes cooperate without trusting each other.

principle 03

Economy before token

Credits must work as boring internal bookkeeping first. A token only wraps an economy that already functions without it — never the other way around.

Now2026 H2

Foundation — the honest miner, generally available

Early access is live: desktop on three platforms, headless Docker nodes, sealed vault, licence hub, the download pipeline. The remaining work is polish that earns trust.

  • shipGreen CI on all three platforms and signed builds (Windows code-signing, Apple notarization).
  • shipDemo tier for keyless copies and engine-search fixes from the audit (refine cadence, restart replay, sparse-window scoring).
  • shipSupport pipeline: key delivery by email, docs, onboarding walkthrough.

done whena stranger can go from the site to a mining node on any OS without talking to us.

2027 H1module

The Evolution Agent — a quant on staff, inside every node

An autonomous AI agent joins the app as a module. The blind evolutionary search gets an observer that reads its results, forms hypotheses and steers.

  • watchSearch health: the agent monitors rounds live — stagnation, overfit smell, wasted exploration — and retunes the explore/refine cadence on evidence.
  • explainPlain-language reports: why this round found what it found, what a formula actually trades on, what died on TEST and why.
  • steerHypothesis-driven mining: the agent proposes universes, timeframes and primitive sets to try next — the search stops being a random walk and becomes a directed one.

done whenan agent-steered node beats a default node on held-out TEST across a season, reproducibly.

2027 H2network

AlphaHub Network — nodes become a society

The licence hub grows into a network layer. Nodes opt in to share what can be shared honestly — performance, never plaintext formulas — and an internal economy starts keeping score.

  • connectThe global leaderboard: sealed champions ranked by network-graded TEST and forward results — one honest table across all participating nodes.
  • earnCredits ledger: uptime, unique finds and forward-track survival earn credits; reveals, agent features and priority spend them. Internal economy, boring on purpose.
  • tradeFormula access market, v1: an owner can grant paid, hub-brokered access to a sealed formula's signal — the formula itself never leaves the vault.

done whena node earns credits it can spend on something it wants, with zero plaintext ever crossing the wire.

2028 H1breeding

The Mutator — evolution at network scale

A network-walking breeder: it visits participating libraries, crosses champions from different nodes — islands exchanging genes — and returns offspring that survive network-wide honest tests. More machines stop meaning merely more tries; they start meaning deeper search.

  • walkIsland migration: the mutator combines solutions that evolved apart — the cross-pollination a solitary node can never have.
  • gradeNetwork referee: offspring face locked tests and forward tracks graded across the whole network before anyone sees them.
  • rewardProvenance & royalties: every offspring carries its lineage; credits flow back to the nodes whose champions were its parents.

done whena mutator-bred formula tops the global leaderboard and its parents' owners get paid for it.

2028 H2economy

Tokenomics — the ledger grows up

By now the credits economy has a year of real history: earnings, spends, royalties. Tokenization wraps that proven ledger — it does not invent value, it settles value that already moves.

  • legalJurisdiction and securities review first — the structure follows the law we choose to live under, not the other way around.
  • mintToken over the ledger: credits become transferable; mining contribution, formula royalties and mutator fees settle on-chain.
  • openExternal liquidity: the internal economy opens its doors — carefully, and only as far as the review allows.

done whena contributor can convert a year of honest mining into something the outside world accepts.
