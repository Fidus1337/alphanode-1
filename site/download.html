Early access · downloads

Pick your machine.

Every build is the same application: the full evolutionary search, the leaderboard, the forward track. No key is needed to install or to mine — formulas stay sealed until a subscription key from your early-access email unlocks them in the app.

exe · windows

Windows

Windows 10/11 · x64

Download the installer

Prefer no installer? Portable .zip — unzip and run AlphaNode.exe.

The build is not code-signed yet, so SmartScreen will warn on first run: choose “More info” → “Run anyway”. One click, once.

app · macos

macOS

Apple Silicon (M1 and newer) · macOS 14+

Download for Mac

Open the .dmg, drag AlphaNode.app to Applications.

Unsigned until our Apple Developer ID lands: on first launch right-click the app → “Open” → “Open” again. After that it opens normally.

deb · linux

Linux

Ubuntu 22.04+ · Debian 12+ · x64

Download the .deb

sudo apt install ./alphanode_amd64.deb — menu entry plus an alphanode terminal command. Any other distro: AppImage, a single portable file.

Python is not needed on the machine — the interpreter and every dependency ship inside, on all three platforms.

docker · headless

Run the node on a server.

The same search without the desktop: one compose file builds the image on your box straight from the .deb above — no registry account, nothing extra to trust — and runs a capped background node with the live status page.

# any Linux server with Docker Compose v2.17+ $ curl -fsSLO https://alphanode.tech/dl/docker-compose.yml $ docker compose up -d --build # live leaderboard + forward track: $ open http://your-server:8787
first start
The node bootstraps its own market data — ten liquid majors at the configured timeframe — and starts round one by itself.
resources
The compose caps CPU (cpus:) and the node keeps its background priority; edit the file to give it more or fewer cores.
your formulas
Everything it mines lands sealed in a named volume. Open them from the desktop app with your key — a server never holds plaintext alpha.

licensing

The key comes to your inbox.

One subscription key per account, entered once in the app. It activates a set number of machines and unlocks the formulas your nodes mined; the search itself runs locally either way.
