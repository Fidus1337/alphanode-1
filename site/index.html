How it works

A strategy factory with a quality gate at every door

The pipeline is a sequence on purpose: each stage exists so a formula earns its way toward your exchange instead of jumping straight from a backtest.

01 · MINE

Evolve

A genetic search breeds formula trees over price, volume and funding — scored through a real portfolio simulator with vol targeting, fees and funding costs. Not a toy backtest.

02 · VALIDATE

Hold out

Fitness is min(TRAIN, VAL) Sharpe. A configurable most-recent slice of history stays locked: it is reported read-only and never enters fitness. Views that rank by it are labeled with a warning, not a highlight.

03 · FORWARD

Track

One click enrolls a champion into the forward track: paper steps appended on closed live bars, fees charged, never rewritten by the app. The record is the record.

04 · TRADE

Deploy

Serve target weights for a formula or a whole portfolio over a local JSON API, or run the node headless in Docker on a server.

Why trust it

The product argues with you. That's the point.

Most strategy tools are built to show you good numbers. AlphaNode is built to make good numbers hard to fake — including by itself.

locked test

The search never sees the held-out data

A configurable most-recent slice of history is fenced off: the evolutionary search can't see it and fitness never uses it. It is reported read-only, next to every formula.

⚠ labels

Cherry-picking is called cherry-picking

Rank anything by held-out results — a leaderboard view, a portfolio — and the app labels it as cherry-picking with the warning that the number is inflated. A lucky draw never gets to pose as skill.

append-only

The forward track is never rewritten

The app only ever appends paper steps on closed bars, with fees charged. No backfills, no do-overs. If a strategy decays, you will see it decay.

battle-tested

We attacked our own engine

Reinforcement learning, meta-labeling, ML ensembles, volatility forecasting, alternative fitness objectives — every overlay we built failed to beat the simple engine out-of-sample. So the simple engine is what ships.

What's in the box

One node, three faces: desktop, terminal, server

desktop

One-button Simple mode

Opens with a single Start button and a power preset — sane defaults do the rest. The full dashboard of settings, analytics and portfolio tools is one click away behind Advanced.

timeframes

15m to 1d bars

Each timeframe keeps its own library and its own honest splits — intraday and daily alphas never mix in one leaderboard.

simulator

Fees and funding included

Every candidate pays execution costs and perp funding inside the simulation. Carry-style alphas are mined on real economics, not free money.

analytics

Regime X-ray

Per-alpha Sharpe in calm and storm volatility regimes, drawdown, CAGR, Sortino, win rate — computed on held-out data, labeled as analysis.

server

Headless & Docker

The same node runs on a server with a live status page, CLI control and a self-stepping forward track. Cap it at any share of your CPU.

signals

Signal API

Target weights and leverage of any champion or portfolio, served as JSON on localhost — plug it into your own execution.

AlphaNode is a desktop and server application. The search runs on your hardware and the formulas it finds are yours; the only thing that leaves the machine is a licence check.

  • debUbuntu / Debian: native installer — menu entry, terminal CLI, no Python needed.
  • AppImageAny Linux: a single portable file.

Plain answers

Does it need my exchange API keys?

No. Mining and forward tracking read public market data. Keys only matter if you wire the signal API into your own execution — and that part runs on your machine too.

Will the mined strategies make money?

Unknown — and anyone who promises otherwise is selling you something. AlphaNode's job is to make sure the numbers you see are honestly measured: held-out tests, real costs, forward tracking. The decision stays yours.

Won't every node find the same formulas?

No. Each install mints a unique node ID that seeds its own search trajectory, so no two nodes mine the same library. What your node finds is yours.

Is my data sent anywhere?

Your library, settings, forward track and signals stay on your disk. The node downloads public candles from the exchange, and a licensed node asks our licence server whether the subscription is live — that call carries your key and a random per-install ID, never your formulas or your data. Unlocking a formula is the one exception: the sealed text goes to the server to be opened, and comes straight back.

What does it run on?

Linux (deb / AppImage), Windows, or any Docker host. The headless Docker node runs on just NumPy and pandas; a laptop core or two is enough to mine around the clock.
