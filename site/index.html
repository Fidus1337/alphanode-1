How it works

    
One engine, four stages. Everything runs locally — data, search,
    simulation, and the strategies it finds are yours alone.

    

      

        
01 · DATA

        
Download history

        
One click fetches OHLCV + funding history for up to 150 Binance USDT-perpetual
        pairs, at the bar size you choose. Snapshots are kept per-timeframe.

      

      

        
02 · EVOLVE

        
Genetic search

        
Formulas like ts_zscore(close,14) breed, mutate and compete.
        A numpy-compiled simulator scores ~0.2s per genome — cross-checked against the
        real engine — so the node chews through thousands of candidates per round.

      

      

        
03 · LIBRARY

        
Keep the survivors

        
Champions land in a persistent library with full segment metrics. Combine the
        top-N into a portfolio with one click — on any timeframe — and export CSV signals
        or a PDF report.

      

      

        
04 · ACT

        
Prove it forward

        
Serve a live signal API, export a paper-trading bundle, or push target weights
        to AlphaHub — a forward-track notary that timestamps your calls
        before the bar closes.

      

    

  






  

    
Anti-overfitting is the whole point

    
Any GP search can print a beautiful backtest. AlphaNode is built so that
    a beautiful backtest is hard to fake — the discipline is wired into the engine,
    not left to your willpower.

    

      

        
Fitness = min(TRAIN, VAL)

        
A strategy is only as good as its worst segment. The search is rewarded
        for robustness across regimes, not for curve-fitting one lucky year.

      

      

        
TEST is locked

        
The held-out window is never used for selection, ranking or seeding. It is
        computed once and shown as an honest out-of-sample estimate — with a cherry-pick
        warning anywhere ranking by TEST would flatter the numbers.

      

      

        
Diversity, not clones

        
Correlation dedup keeps the Hall of Fame diverse, a complexity penalty prunes
        bloated formulas, and an activity filter kills signals that barely trade.

      

    

  






  

    
Neuro Advisor — optional LLM co-pilot

    
When the search plateaus, a Claude model reads the current champions and
    proposes fresh formula ideas. The LLM never scores anything — every proposal goes
    through the same simulator and the same locked-TEST discipline as random mutations.
    It just widens the search.

    

      
Bring your own key

        
Works with your Anthropic API key. Stored locally with 0600 permissions —
        never in settings files, never sent anywhere but Anthropic.

      
Pick your model

        
Opus for the deepest ideas, Sonnet for balance, Haiku for pennies —
        switchable from the GUI.

      
Budget control

        
Hard cap on LLM consults per search round — set it to 1 and the advisor costs
        you a few cents a day.

      
Full provenance

        
Every advisor-born alpha carries a 🧠 badge through the leaderboard, library and
        CSV exports — you always know what the LLM contributed, and consult stats and
        errors are shown live.

    

  






  

    
AlphaHub — a forward-track notary

    
Backtests can be argued with; a timestamped forward track cannot.
    AlphaHub receives your target weights before the bar closes, then scores them on
    the next bar using public exchange prices. No trust required in either direction.

    

      

        
Your formula stays home

        
The protocol carries weights only — there is no field for the formula at all.
        The hub proves your alpha works without ever seeing what it is.

      

      

        
Self-sovereign identity

        
Your node generates an Ed25519 keypair on first run; every push is signed.
        No accounts, no passwords, no API keys issued by anyone.

      

      

        
Honest scoring

        
Returns are gross-normalized — leverage can't inflate them. Late pushes are
        rejected by the clock, and new nodes carry a 60-day quarantine tag so short lucky
        streaks don't sell.

FAQ

    

    

      Does AlphaNode guarantee profits?
      
No — and be suspicious of anyone who says otherwise. Every number AlphaNode shows is
      a hypothetical backtest, and the app says so on every export. What AlphaNode
      guarantees is discipline: a locked held-out window, robustness-first fitness, and
      a forward-track notary so you can prove — to yourself first — whether an alpha survives
      contact with the future. Nothing here is investment advice.

    

    

      What do I need to run it?
      
A Linux (AppImage / .deb) or Windows 10+ (installer / portable zip) machine and an
      internet connection for market data. A few CPU cores are enough; more cores = faster
      search rounds. No GPU needed. The Neuro Advisor additionally needs your own Anthropic
      API key.

    

    

      Do my formulas or data ever leave my machine?
      
No. Search, simulation and the library are fully local. The only outbound traffic is
      market data downloads, optional advisor calls to Anthropic (your key, your account), and
      optional AlphaHub pushes — which carry target weights only, never formulas.

    

    

      Which markets and timeframes?
      
Binance USDT-M perpetual futures — up to 150 pairs — on 15m, 1h, 4h and 1d bars.
      Funding rates are part of the data and the simulation, so carry-style alphas are
      searchable too.

    

    

      How is this different from a backtesting library?
      
A backtester scores the strategies you write. AlphaNode generates
      strategies: it searches a formula space that strictly contains the classic hand-written
      signals (Bollinger, MA-cross, momentum…) and everything between, while the engine's
      fixed machinery — inverse-vol sizing, vol targeting, position inertia, fees, funding —
      keeps every candidate realistic.
