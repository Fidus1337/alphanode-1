Neuro Advisor

An optional LLM co-pilot for the search. The division of labour is strict: the LLM proposes, the simulator judges. Claude reads the current champions and the search state, proposes new formula candidates — and every proposal then passes through exactly the same simulation, fitness, degeneracy and correlation filters as any random mutation. The LLM cannot score, rank or promote anything.

Why it helps

Genetic search is great at refining structures it has already found and bad at inventing a structurally new idea mid-run. The advisor fires when the search plateaus and injects candidates from a different distribution — priced volatility patterns, funding carry structures, cross-sectional twists — that evolution then refines. Advisor-born alphas that survive are often the library's most distinctive entries.

Setup

  1. In NEURO ADVISOR, tick enable.
  2. Paste your Anthropic API key and press Check key — the GUI probes the selected model live and tells you exactly what works or fails.
  3. Pick a model and a per-round consult cap. Start with 1 consult/round.
ModelCharacter
claude-opus-5Deepest, most original proposals (default).
claude-sonnet-5Great balance of quality and cost.
claude-haiku-4-5Cheapest — still useful for widening the search.

Cost control

Max LLM consults is a hard per-round cap. At 1, the advisor consults once per search round at most — typically cents per day; at 0 it never fires. LLM usage is billed by Anthropic to your key; AlphaNode adds no markup and makes no calls beyond the cap.

Privacy & key handling

  • The key is stored in a separate local file with 0600 permissions — never in settings files, never in exports, never in logs.
  • Advisor requests go to Anthropic's API only, and contain formulas/metrics of the current search — no personal data, no account info.

Transparency

You always see what the LLM did and whether it earned its keep:

  • every advisor-born alpha carries a 🧠 origin badge through the leaderboard, the library and CSV exports;
  • the status line shows live consult stats — consults / proposed / accepted;
  • failures are loud: an invalid key or API error is shown in red in the GUI and on the status page, never silently swallowed.
The advisor is strictly additive: with it off (or its budget at 0), the node is the classic GP search, byte-for-byte. You can A/B it per round and compare 🧠 vs GA-born entries in your own library.
