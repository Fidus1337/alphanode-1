AlphaHub — the forward-track notary

A backtest is an argument; a forward track is a fact. AlphaHub is a small server that timestamps your target weights before the bar closes and scores them on the next bar from public exchange prices. It turns "trust me, it works" into a verifiable ledger — without ever seeing your formula.

What the hub receives — and what it never does

Sent (signed)Never sent
node id + name, timeframe, bar close time, target weights per symbol your formula, your parameters, your data, your code

The protocol has no field for a formula at all — disclosure is structurally impossible, not merely promised.

Identity: keys, not accounts

On first run your node generates an Ed25519 keypair locally. Your node id is derived from the public key; the private key never leaves your machine and signs every message. Registration is a single signed hello — no email, no password, nothing to leak or reset. Delete the identity file and you're a fresh node.

Pushing a signal

  1. Select an alpha in the leaderboard and press ⇪ Hub (or use the row menu).
  2. The node computes the alpha's current target weights on live market data — on the daily timeframe through the real engine, intraday through the search engine.
  3. The weights are signed and sent for the next bar close. The hub accepts them only while that bar is still open — by its own clock.

Pushes are deliberately manual one-shots: you choose what goes public and when. Re-pushing before the deadline overwrites (last write wins).

Scoring — designed to be ungameable

bar return = Σ (weight × symbol return) / Σ |weight|
  • Gross-normalized: scaling all weights ×10 changes nothing — leverage cannot inflate the score. The ledger measures direction quality, as if every node ran $1.
  • Public prices: settlement uses exchange klines anyone can re-fetch and verify.
  • Hard deadline: a push a second after the close is rejected. No hindsight.
  • Quarantine: a node's first 60 days are visibly tagged — a week of luck doesn't make a track record.

The leaderboard

Per node and timeframe: settled bars, total return, annualized forward Sharpe and hit rate — plus a live list of recent pushes waiting for their bar. Missing a bar is not penalized; the ledger simply has no entry for it.

Running your own hub

The hub is a single Docker container (FastAPI + SQLite) with a built-in scorer loop. Point your nodes at its URL, approve registrations (or enable auto-approve), and you have a private forward-track board for your team.

Key loss = identity loss: back up the identity file if the track record matters to you. The hub cannot reset what it never had.
